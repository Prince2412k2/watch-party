# Details

Title metadata and actions, rendered **in the library itself**.

## Purpose

> "The backdrop will not be this dark and will show the movie's details in
> the library itself — similar to the show screen, where movies will act
> like episodes."

This is the change that removed a whole navigation level. There is no
separate movie detail page: the details for the focused item render on the
stage, above the rail, and Enter **plays** rather than opening anything.

That is why `activationFor` returns `play` for a movie and `open` only for
a box set — the details are already on screen, so there is nothing to open.

## Download state is a word, not a spinner

```
idle   → "Download for offline"
busy   → "Starting download"
queued → "Downloading"
failed → "Download failed — try again"
```

Each state says what happened. `failed` says what to do about it. A bare
red icon would satisfy neither.

## Rules

| # | Rule | Enforced by |
